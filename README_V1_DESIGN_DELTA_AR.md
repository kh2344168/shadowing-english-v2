# تعديل تصميم V1 على النسخة المرسلة للشريحتين الأولى والثانية

هذا الأرشيف يحتوي 13 ملفًا تغيّرت فقط، ولا يحتوي المشروع كاملًا. النسخة التي بُني عليها التعديل هي `shadowing-english-v2-day2-slices-1-2.zip` المرسلة سابقًا؛ SHA-256: f4d5915fd322f7c4adae1857e72ab507bd406bb13bd8bf6d363a9225bb24577a.

الأسلم: افتح PowerShell من جذر المشروع بعد فك النسخة السابقة في مجلد جديد، وطبّق ملف Patch المرفق منفصلًا بعد استبدال مساره بمكان تنزيله عندك:

```powershell
git apply --check "C:\Users\YOUR_NAME\Downloads\shadowing-v1-design-current-slices.patch"
git apply "C:\Users\YOUR_NAME\Downloads\shadowing-v1-design-current-slices.patch"
npm run build:frontend
npm run test:frontend
```

إذا فشل `git apply --check` فلا تُجبِر التطبيق ولا تنسخ الملفات فوق مشروع تغيّر محليًا؛ ابعت لي الخطأ لنطبقه على نسختك الفعلية. للمراجعة اليدوية فقط، الملفات الموجودة هنا مرتبة بنفس المسارات داخل المشروع.

ما تغير: شاشة الدخول وفق قالب V1، واجهات لوحة Admin والمجموعات والأدمنز، والحالة الفارغة لطالب V1. عمليات V2 للمجموعات/الحسابات/الدخول لم تتغير، ولم يتغير Backend أو SQL أو الترحيل. لا يوجد زر نشر أو إحصاءات وهمية. بقية صفحات الأعمال ما زالت قيد الخطة، والمقارنة البصرية المباشرة على جهازك مطلوبة.
