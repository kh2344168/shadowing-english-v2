# حماية ملف ربط الأداة المحلية — #14

التاريخ: 23 أكتوبر 2026. تحسين جزئي.

`shadowing-link.json` يحتوي رمز اتصال محليًا. كان ملف التثبيت ومجلده
يرثان صلاحيات Windows الافتراضية. صار المثبت يقصر الوصول إلى مجلد الأداة
والملف على حساب Windows الحالي وSYSTEM والمديرين، سواء في تثبيت جديد أو
عند إعادة تشغيل المثبت لأداة تعمل بالفعل. هذا مهم لأن تغيير الإعدادات
ينشئ ملفًا مؤقتًا ثم يستبدل ملف الربط؛ الملف المؤقت يرث حماية المجلد.

اختبار ACL أنشأ مجلدًا تجريبيًا بلا أسرار، أعطاه صلاحية قراءة واسعة عمدًا،
ثم تحقق من إزالة هذه الصلاحية عن المجلد وملف الربط وملف مؤقت جديد. نجح
الاختبار. حزمة التنزيل المولدة تطابق 13 ملف مصدر ولا تحمل رمز ربط مسبقًا؛
المتصفح يضيف ملف الربط الخاص بالحساب عند التنزيل.

طُبقت الصلاحيات أيضًا على نسخة الأداة المثبتة في جهاز التطوير الحالي،
ثم أكد `/v1/health` أن الخدمة ما زالت تعمل والربط صحيح. لم تُحذف ملفات
أو نماذج أو نتائج دروس، واحتُفظ بمجلد الاختبار.

هذا **لا يغلق #14 كاملًا**: ZIP الذي نزله الأدمن ونسخة الرمز في
`localStorage` لا يحميهما ACL الخاص بمجلد التثبيت. يلزم قرار مستقل حول
طريقة إقران لا تترك رمزًا دائمًا في المتصفح، من غير إرهاق الأدمن بإعادة
الربط كل مرة.

```powershell
& .\tests\local-processor-acl-check.ps1
python infrastructure/scripts/build-local-processor-package.py
```
