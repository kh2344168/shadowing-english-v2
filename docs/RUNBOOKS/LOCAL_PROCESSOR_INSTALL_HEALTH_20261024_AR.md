نسخة البروتوكول وهوية الأداة وأن الربط صحيح قبل إعلان نجاح التثبيت أو
إعادة استعمال عملية قائمة. لو شغل برنامج آخر المنفذ تظهر رسالة واضحة.

كاملًا ولم نعد تنزيل النماذج. حزمة التنزيل المضمنة في الواجهة أُعيد
