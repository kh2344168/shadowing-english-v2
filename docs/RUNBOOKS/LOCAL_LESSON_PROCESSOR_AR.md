# V2 — تجهيز دروس Shadowing على كمبيوتر الأدمن

الفكرة نُفّذت كأداة مثبتة على الكمبيوتر تتصل بصفحة الأدمن. حزمة التنزيل الصغيرة تحمل كود الأداة وملف ربط خاص بالحساب والموقع؛ المحرك والنموذج يُثبتان محليًا. النتيجة تُراجع في الموقع ثم تُحفظ عبر Admin API الحالي، ويظل النشر خطوة مستقلة. عدد الطلاب لا يشغّل هذه المعالجة ولا ينزّل نموذجها.

هذه الشريحة تجهّز الصوت من **النص الإنجليزي الموجود والمطابق للتسجيل**. كل سطر يصبح مقطع Shadowing. توليد النص، Vocabulary/Quiz، وLLM لشات الطالب تبقى في مراحل الميزات التالية. لم يُعدَّل `APPROVED_RULES.md` أوV1 أوSchema أوMigration. أُصلح خطأ ترجمة مقارنة SHA-256 سابقًا، وأضيف في 30 سبتمبر تخزين WAV النهائية في Azure Blob الخاصة خلف إعداد Backend. لا تُرفع بيئة AI أونموذجها. [دليل التخزين](AZURE_SHADOWING_MEDIA_AR.md) يوضح إعداد Production والتطوير المحلي.

## تقييم الفكرة والقواعد

| النقطة | التطبيق في V2 |
|---|---|
| الاستضافة الخفيفة للطلاب | المحرك والنموذج على كمبيوتر المنشئ. حزمة الموقع كود صغير يُنزّل عند الطلب، وصفحة الأدمن lazy. الصوت النهائي المحفوظ يحتاج تخزينًا وخدمة تنزيل للطالب. |
| أداة تبقى بعد مسح بيانات المتصفح | التثبيت في LocalAppData؛ مسح بيانات الموقع يزيل مفتاح الربط من المتصفح فقط. يمكن استيراد ملف الربط الموجود على الكمبيوتر. |
| تنزيل مرة واحدة وإعدادات تلقائية | `Install.cmd` يجهّز البيئة والمحرك وبيانات اللغة والنموذج واختصارات Start Menu. إعدادات الموقع داخل الحزمة وتُرسل مجددًا عند أمر معالجة صريح. |
| صلاحيات إنشاء المحتوى | الصفحة ومنشئ الدرس لحساب Admin؛ دور Teacher الخاص بالمتابعة لم يتغير. |
| عزل المستخدمين | الربط يطابق الحساب وأصل الموقع؛ مفتاح المتصفح لكل حساب، والمسودة المؤقتة في الذاكرة تتحقق من الحساب مجددًا. ملفات المعالجة المحلية معزولة لكل حساب وأصل. |
| Backend مصدر الحقيقة | الأداة تنتج ملفات تجهيز، ولا تتصل بقاعدة SQL. بيانات الدرس التجاري تأتي من الحفظ الصريح عبر API الموجود. |
| مراجعة AI وفصل الحفظ والنشر | النص والحدود وWAV وSHA-256 تُتحقق قبل النقل. تأكيد مراجعة الصوت والنص مطلوب؛ تعديل المسودة المستوردة يلغي التأكيد. نقل المسودة لا يحفظها؛ الحفظ لا ينشرها. |
| عدم تغيير المنشور | تعديل الحدود يغير ملفات محلية قبل الحفظ. لم تُضف API لتعديل LessonVersion منشور أوتغيير تقدم الطالب. |
| العمليات الطويلة والتشخيص | مهمة واحدة، مراحل وتقدم، استعادة متابعة مهمة محلية، إلغاء ينهي worker وFFmpeg التابع، وحالات توقف/فشل. التشخيص يستخدم المعرفات والحجم والمدة وأكواد الأخطاء. |
| لا كتابة تجارية خفية | فتح الصفحات وقراءة الحالة والنتيجة لا تحفظ ولا تنشر. عند إعادة تشغيل الأداة تُعلَّم المهمة المحلية المنقطعة فاشلة، دون تشغيلها تلقائيًا ودون أي كتابة للموقع. |

التثبيت الأول لا يمكن تنفيذه بصمت من صفحة ويب؛ Windows يحتاج تشغيل الحزمة من صاحب الكمبيوتر، وقد يحتاج إذنًا لتثبيت runtime، والمتصفح قد يطلب إذن اتصال محلي. بعد ذلك لا توجد إعدادات Python أونموذج يحتاج المستخدم كتابتها يدويًا في الحالة العادية.

## التشغيل أول مرة

1. فك **مصدر V2** في مجلد جديد. ثبّت اعتماديات الواجهة من lockfile عبر `npm ci` بعد إغلاق أي process يقفل الملفات. اتبع [دليل إنشاء ونشر الدرس](SHADOWING_AUTHORING_SLICE.md) لتشغيل API Development وقاعدة V2 التجريبية الموجودة. لا تطبّق أي ترحيل على V1 أوالقاعدة المعتادة بسبب هذه الإضافة.
2. سجّل الدخول بحساب Admin وافتح «معالجة المحتوى». اضغط «نزّل أداة Windows». الملف الذي ينتج مرتبط بحسابك وبأصل الموقع المفتوح؛ لا تشاركه مع حساب آخر.
3. اختر **Extract All** للحزمة ثم شغّل `Install.cmd`. يحتاج Windows x64 وwinget واتصالًا بالإنترنت أثناء الإعداد. يثبت Python 3.12 وFFmpeg، ويجهّز Microsoft Visual C++ Runtime عند غيابه، ثم venv خاصة بالمحرك. Windows قد يطلب موافقة لأول إعداد.
4. ينتج اختصار **Shadowing V2 Local Processor** في Start Menu. ستعمل نافذة محلية؛ احتفظ بها مفتوحة أثناء المعالجة. ارجع إلى نفس المتصفح واضغط «تحقق من الاتصال»، واسمح باتصال محلي إذا طلب المتصفح ذلك.
5. اختر ملف المعلم، عنوانًا ونصًا إنجليزيًا مطابقًا للصوت، كل سطر مقطع تدريب. اضغط «عالج الدرس محليًا». لا يُرسل الملف الأصلي إلى API الموقع.
6. اسمع كل مقطع وراجع النص والبداية والنهاية. عند تعديلها اضغط «طبّق حدود المقاطع والنص» ثم راجع المقاطع الجديدة. أكد المراجعة واضغط «انقل إلى منشئ الدرس».
7. في المنشئ راجع المسودة ثم اضغط «احفظ الدرس». اختر المجموعة والموضع واضغط «انشر الدرس للمجموعة» من خطوة منفصلة. هذه الأوامر تستخدم Backend الحالي وصلاحياته وCSRF وحدوده.

موضع التثبيت:

```text
%LOCALAPPDATA%\ShadowingEnglishV2\LocalProcessor
```

الإعدادات الافتراضية: WhisperX 3.8.6، محاذاة الإنجليزية بواسطة `WAV2VEC2_ASR_BASE_960H`، CPU حتى أربعة threads، WAV PCM16 أحادي القناة 16 kHz، هامش 150 ms قبل الكلام و100 ms بعده. الهامش قابل للتعديل بين 0 و1000 ms. النموذج نفسه نحو 360 MiB؛ إجمالي المحرك وبيانات اللغة والبيئة أكبر ويُحفظ على الجهاز. بيانات اللغة تُجهز أثناء التثبيت حتى لا يبدأ تنزيلها عند أول درس.

الحدود: مصدر حتى 100 MB و10 دقائق؛ 1–20 سطرًا، حتى 1000 حرف لكل سطر؛ WAV نهائي حتى 2 MB لكل مقطع؛ مهمة واحدة في الوقت نفسه؛ حتى 30 مهمة محفوظة لكل حساب/أصل. مدة المعالجة والذاكرة تعتمد على الملف والجهاز؛ جُرّب المحرك الحقيقي هنا على عينة قصيرة فقط.

## الأداة موجودة أوالاتصال ممنوع

- **الأداة موجودة والربط محفوظ:** الصفحة تتحقق من اتصالها عند الفتح؛ شغّلها من Start Menu إذا كانت مغلقة.
- **مسحت بيانات الموقع:** شغّل الأداة واستورد `shadowing-link.json` من مجلدها. لا تعِد تنزيل النموذج.
- **غيّرت حساب الأدمن أوعنوان الموقع:** أغلق الأداة ثم نزّل وشغّل حزمة الربط الجديدة. النموذج يبقى، وملفات الحساب السابق تبقى في نطاقها المستقل. يوجد ربط نشط واحد لكل تشغيل أداة.
- **المتصفح يمنع loopback:** شغّل الأداة ثم اختصار **Shadowing V2 Prepare Lesson ZIP**. اختر ملف الصوت وTXT إنجليزي UTF-8 وعنوان الدرس ومكان ZIP. بعدها استورد ZIP في الموقع وأكد المراجعة. لا يعتمد هذا المسار على إذن الموقع للاتصال المحلي.
- **إصلاح التثبيت:** أغلق الأداة وشغّل `Install.cmd` مجددًا من مجلد التثبيت أومن حزمة حديثة. الملفات والنماذج الموجودة تبقى.
- **تنظيف النتائج:** تنزيل ZIP ثم حذف الملفات المحلية أمران صريحان. حذف ملفات تجهيز محلية لا يحذف درسًا محفوظًا في V2. يمكن حذف مجلدات jobs القديمة يدويًا بعد الاحتفاظ بنتائجها؛ لا تحذف ملف الربط أوالنماذج إذا أردت إعادة استخدامها.

الموقع المنشور يحتاج HTTPS. إن كانت الاستضافة تستخدم CSP، يجب أن تسمح سياسة صفحة الأدمن باتصال `http://127.0.0.1:43127` وبمعاينة الصوت `blob:`. لا توسّع CORS إلى wildcard؛ الأداة تقبل أصل الموقع الموجود في ملف الربط فقط ولا تستقبل cookie الموقع أوجلسة دخوله.

## التحقق والصيانة

```powershell
npm run test:frontend
npm run lint
npm run format:check
py -3.12 -m unittest discover -s tests -p local_processor_test.py -v
npm run test:e2e:local-processor
```

اختبارات Python تستخدم PCM حقيقية وHTTP loopback، لكن runner التجريبي فيها لا يختبر دقة AI. اختبارات Playwright تعزل الموقع بواسطة API mock وتختبر النقل والمراجعة وطلبات الحفظ والنشر، ولا تختبر SQL أوصلاحيات API الحقيقية. إعدادها منفصل عن اختبار رحلة الطالب المصادق القديم، ويستخدم 4206 و43127؛ أغلق أداة التشغيل الحقيقية قبل تشغيلها حتى لا يتعارضا.

إذا تغير أي ملف مصدر داخل `infrastructure/scripts/local-processor`، أعد توليد ملف التنزيل قبل بناء الواجهة:

```powershell
py -3.12 infrastructure/scripts/build-local-processor-package.py
```

ملف `frontend/public/downloads/local-processor-package.json` يجب أن يطابق المصدر؛ اختبار Python يتحقق من ذلك. لا تضمّن `.venv` أو`models` أو`jobs` أو`shadowing-link.json` الخاص بالمستخدم في Git أوملفات الاستضافة.
