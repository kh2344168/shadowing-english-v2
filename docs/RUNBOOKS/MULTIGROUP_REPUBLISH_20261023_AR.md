# إعادة نشر درس معتمد عبر مجموعات كثيرة

التاريخ: 23 أكتوبر 2026. تحسين جزئي ضمن #25 و#7.

اختبار SQL Server محلي معزول بنى 30 مجموعة، لكل منها 100 طالب، و10 محاولات
Shadowing لكل طالب. كل المجموعات نشرت الدرس نفسه من مخرج WhisperX حقيقي.
بعد اعتماد نسخة AI جديدة، أعاد الناشر إصدار منهج كل مجموعة ونقل التقدم
و30 ألف محاولة. لم يحذف الاختبار قواعد بيانات أوحسابات أوصوتًا.

| الحالة | زمن النشر لكل الـ30 مجموعة | كيانات EF المتتبعة بعده | النتيجة |
| --- | ---: | ---: | --- |
| قبل تحسين تتبع المجموعات | 5079 ms | 3090 | نقل 3000 تقدم و30000 محاولة |
| بعد فصل كائنات النسخ المكتملة | 4407 ms | 0 | نقل 3000 تقدم و30000 محاولة |

الناشر صار يفصل عن `DbContext` الكائنات الجديدة التي أنشأها هو بعد نجاح
معاملة كل مجموعة، مع إبقاء الكائنات التي كان المستدعي يتتبعها أصلًا. هذا
يمنع تراكم آلاف الكائنات أثناء المرور على مجموعات كثيرة. نتائج الزمن من
تشغيل واحد لكل حالة، لذلك لا نعامل فرق الزمن وعدًا ثابتًا.

نجحت خمس حالات `--ai-publication-check` لاختيار المحتوى وإبقاء التاريخ،
واختبار SQL الحقيقي لـ3 مجموعات و30 مجموعة. بقيت مسائل منفصلة قبل إغلاق
#25/#7: منهج متعدد الدروس، قراءة الطلاب أثناء معاملات النشر، وقياس حجم
القاعدة بعد نشرات متكررة. لا يزال نقل المحاولات إلى نسخة منشورة جديدة
يضيف سجلات تاريخية؛ لم تُحذف بيانات الطلاب أوتُغير سياسة الاحتفاظ.

إعادة اختبار 30 مجموعة:

```powershell
& .\.local\tools\dotnet-10.0.402\dotnet.exe run --project tests/ShadowingEnglish.MediaChecks/ShadowingEnglish.MediaChecks.csproj -c Release -- --processor-group-republish-load '<manifest path>' 30 100 10
```
