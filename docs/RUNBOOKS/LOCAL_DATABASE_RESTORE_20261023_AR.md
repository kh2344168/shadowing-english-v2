# تجربة النسخ الاحتياطي والاستعادة لقاعدة العرض المحلية

في 23 أكتوبر 2026 اختبرنا قاعدة `ShadowingEnglishV2_Demo_20261018_01` على SQL Server Express:

1. أُنشئت نسخة احتياطية جديدة باسم `ShadowingEnglishV2_Demo_20261018_01_20261023.bak` في مجلد النسخ الافتراضي لخادم SQL. استخدمنا `COPY_ONLY` و`CHECKSUM`. إصدار Express لا يدعم `COMPRESSION`، فنجح الأمر من غيره.
2. نجح `RESTORE VERIFYONLY ... WITH CHECKSUM` للملف.
3. استُعيدت النسخة إلى قاعدة **جديدة** باسم `ShadowingEnglishV2_RestoreCheck_20261023` مع ملفات بيانات وسجل جديدة، من غير استبدال القاعدة الأصلية أو حذف ملف.
4. القاعدة المستعادة `ONLINE`، ونجح `DBCC CHECKDB` من غير أخطاء. تطابقت أعداد الصفوف وقت النسخ في جداول الحسابات (14)، الدروس المنشورة (3)، تقدم المراحل (21)، المحاولات (47)، وسجل الترحيلات (16).

النسخة والقاعدة المستعادة موجودتان على الجهاز للمراجعة. هذه التجربة تثبت إمكانية استعادة **قاعدة العرض المحلية في وقت النسخ**. لا تثبت وجود نسخة احتياطية قابلة للاستعادة لقاعدة Azure؛ يلزم اختبار مستقل هناك بعد استعادة الوصول للإعدادات، ومن دون إنشاء خدمة مدفوعة.
