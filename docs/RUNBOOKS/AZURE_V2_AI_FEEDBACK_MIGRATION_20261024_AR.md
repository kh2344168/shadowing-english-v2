# تجهيز ترحيل نتيجة AI على Azure — جزء من #9

التاريخ: 24 أكتوبر 2026. ولّدنا ملف SQL idempotent من ترحيل EF الرسمي:
`AZURE_V2_AI_FEEDBACK_MIGRATION_20261024.sql`. يوسع عمود
`StudentPracticeAttempts.FeedbackJson` إلى `nvarchar(max)` ويسجل رقم
الترحيل إذا لم يكن مسجلًا. لا يحذف صفوف الطلاب.

**لا تشغّله على Azure قبل فحص سجل `__EFMigrationsHistory` هناك.** الملف
يبدأ *بعد* `20261023002003_CreateVoiceDailyUsageTable` ويفترض تطبيق كل
الترحيلات السابقة. إن كانت قاعدة Azure أقدم، يجب توليد سكربت من آخر
ترحيل موجود فيها إلى آخر ترحيل في الكود، ومراجعته أولًا.

تحققنا محليًا أن ترحيل قاعدة العرض موجود مرة واحدة، والعمود `nvarchar(max)`،
وأن تشغيل السكربت مرة ثانية لا يغير النتيجة. تطبيق Azure مؤجل حتى يتوفر
تسجيل دخول Azure وفحص نسخها الاحتياطي وسجل الترحيلات. لا تنشر كود AI الذي
يعتمد على العمود الجديد إلى Azure قبل تطبيقه.
