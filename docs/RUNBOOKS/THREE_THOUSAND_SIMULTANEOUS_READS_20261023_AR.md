التاريخ: 23 أكتوبر 2026. القياس على جهاز التطوير المحلي، وليس على الاستضافة.

عدّلنا أداة الحمل لتفصل تزامن تسجيل الدخول عن تزامن طلبات الطالب. أنشأت
3000 حساب وجلسة مستقلة داخل قاعدة SQL Server المعزولة. سجلت الدخول بحد
300 طلب في اللحظة، ثم أطلقت 3000 طلب في اللحظة لكل من المنهج وملخص الدرس
وصوت درس واحد ناتج من WhisperX الحقيقي. تحققت الأداة من كود HTTP ومحتوى
الصوت لكل حساب. لم تحذف الاختبارات حسابات أو ملفات أو قاعدة البيانات.

يكشف زمن انتظار مرتفعًا. TestServer داخل العملية لا يقيس شبكة الطلاب،
Cloudflare، Azure، المتصفح، أو سرعات رفع الصوت. بيانات التجربة درس واحد
وصوت نحو 67 KB، ولا تشمل محادثة AI أو تسجيلات الطلاب. لا يجوز اعتبار
النتيجة وعدًا بأن الموقع المنشور سيخدم 3000 طالب بسرعة.
