# اختبار الأداة المحلية مع مسار الدرس الحقيقي — البند #30

التاريخ: 2026-10-23. الاختبار محلي على Windows، وليس على Azure.

1. استخدمنا نسخة WhisperX المثبتة والعاملة على جهاز خالد في `127.0.0.1:43127`، وليست محرك الاختبار المحاكي. عالجت ملف `day2-hello.wav` بنص مطابق، وأنتجت مقطع WAV واحدًا. تحققنا من SHA-256 للمقطع ومن سلامة ZIP الناتجة. بقيت النتيجة المحلية كما هي.
2. شُغّل اختبار `--processor-real-e2e` على قاعدة SQL Server Express مستقلة باسم `ShadowingEnglishV2_ProcessorE2E_20261023`. طبّق ترحيلات V2، وأنشأ حسابي اختبار ومجموعة خاصة بهذا الاختبار فقط.
3. أرسل الاختبار ناتج WhisperX نفسه إلى مسار حفظ الدرس المصادق للأدمن. تحقق من حفظ النص في SQL والصوت في تخزين Development المحلي.
4. أنشأ منهجًا، ربطه بمجموعة الاختبار ونشره. دخل حساب الطالب التجريبي، فوجد الدرس المنشور واسترجع صوت المقطع. بايتات الصوت المسترجع طابقت ناتج الأداة المحلي بالضبط.

نتيجة التشغيل: **PASS** في مرحلتي الحفظ والنشر/استرجاع الطالب. قاعدة الاختبار وحساباتها وملف الصوت التجريبي باقية للمراجعة؛ لم نحذف قاعدة أو ملفًا.

حدود الدليل: شُغلت واجهات API الحقيقية مع SQL Server والتخزين المحلي، لكن خطوات النقر في المتصفح لم تُجرَ في هذا الاختبار؛ مراجعة الأزرار والموبايل مستقلة في #31. لم نختبر جهاز مدرس آخر أوAzure Blob أوتحميل درس طويل مدته 10 دقائق. هذا الاختبار يثبت سلسلة البيانات المحلية من المحرك الحقيقي حتى صوت الطالب المنشور، ولا يثبت سهولة تثبيت الأداة عند مدرس جديد (#21).
