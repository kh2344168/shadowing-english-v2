# معرفة النسخة المعروضة

افتح `/build-info.json` على نفس رابط الموقع. الحقل `commit` هو رقم نسخة GitHub التي بُنيت منها حزمة الواجهة والـAPI، و`buildUtc` وقت البناء بالتوقيت العالمي.

إذا كان `dirty` يساوي `true`، فالنسخة المحلية تحتوي أيضًا على تعديلات غير محفوظة في Git؛ رقم الـcommit وحده لا يصفها بالكامل. لا تُقدّم هذه النسخة على أنها مطابقة لفرع GitHub. نسخة GitHub Actions النظيفة تحمل `dirty: false`.

النشر إلى Azure مرتبط بفرع `deploy/staging` عند تفعيل متغير `AZURE_DEPLOY_ENABLED`. الرفع إلى أي فرع آخر لا يحدث موقع Azure تلقائيًا. قبل مشاركة رابط تجربة، قارن `commit` مع الفرع المقصود، ثم اختبر تسجيل الدخول ورحلة الطالب على نفس الرابط.
