# قياس حمل الطالب المحلي — 23 أكتوبر 2026

## ما الذي قيس؟

حسابات طالب مختلفة داخل قاعدة SQL Server المعزولة
`ShadowingEnglishV2_ProcessorE2E_20261023`. لكل طالب جلسة تسجيل دخول مستقلة
وعضوية في مجموعة ذات درس منشور من مخرجات WhisperX الحقيقية. نفذ الاختبار
تسجيل الدخول بنفس طلب CSRF الذي ترسله الواجهة، ثم قراءة صفحة المنهج وملخص
الدرس، ثم قراءة ملف الصوت والتحقق من محتواه.

يستخدم الاختبار ASP.NET TestServer مع SQL Server المحلي والتخزين المحلي. لا يقيس
شبكة الإنترنت أو Cloudflare أو Azure أو تحميل الصفحة في المتصفح. لا يحذف
حسابات الاختبار أو ملفات الصوت أو قاعدة البيانات بعد التشغيل.

هذه النتائج تكفي لإثبات أن المسارات الأربعة عملت محليًا بهذا الحمل دون أخطاء.
لا تثبت قدرة الاستضافة المجانية أو الموقع العام على 3000 طالب متزامن. يلزم
اختبار شبكي من أجهزة منفصلة، وبيانات دروس أقرب للواقع، وقياس CPU/ذاكرة/قاعدة
البيانات قبل تقديم هذا الوعد. ذيل زمن تسجيل الدخول عند 3000 حساب يحتاج تحليلًا
للتفريق بين كلفة التحقق من كلمات المرور، ازدحام SQL، وجدولة TestServer.
