## ما الذي قيس؟

حسابات طالب مختلفة داخل قاعدة SQL Server المعزولة
`ShadowingEnglishV2_ProcessorE2E_20261023`. لكل طالب جلسة تسجيل دخول مستقلة
وعضوية في مجموعة ذات درس منشور من مخرجات WhisperX الحقيقية. نفذ الاختبار
تسجيل الدخول، ثم قراءة صفحة المنهج، ثم قراءة ملف صوت الدرس والتحقق من محتواه.

يستخدم الاختبار ASP.NET TestServer مع SQL Server المحلي والتخزين المحلي. لا يقيس
شبكة الإنترنت أو Cloudflare أو Azure أو تحميل الصفحة في المتصفح. لا يحذف
حسابات الاختبار أو ملفات الصوت أو قاعدة البيانات بعد التشغيل.
