# قراءة مجموعة الطالب والمنهج في استعلام واحد — #24

التاريخ: 23 أكتوبر 2026. تحسين جزئي.

صفحة منهج الطالب كانت تقرأ المجموعة ثم تعود إلى SQL لقراءة النسخة المنشورة.
أصبحت القراءة باستعلام واحد مع ربط اختياري حتى يبقى اسم المجموعة ظاهرًا
قبل نشر أي منهج. ما زال فحص دور الطالب الحي وفحص موعد إتاحة النسخة قائمين.

نجح بناء Release و42 فحصًا في مجموعة MediaChecks باستخدام SQLite داخل
الذاكرة ومحاكي Azurite داخل الذاكرة. أضفت تحققًا من اسم المجموعة ورقم
النسخة قبل النشر وبعده. نجح أيضًا اختبار 3000 جلسة مستقلة على TestServer
وقاعدة SQL Server المعزولة، دون أخطاء في المنهج أو ملخص الدرس أو الصوت.

| قراءة 3000 طلب متزامن | P95 قبل هذا التعديل | P95 بعده | أخطاء بعده |
| --- | ---: | ---: | ---: |
| المنهج | 6226 ms | 6363 ms | 0 |
| ملخص الدرس | 4962 ms | 4955 ms | 0 |
| الصوت | 6056 ms | 5628 ms | 0 |

كل رقم من تشغيل واحد؛ لا يثبت الجدول تحسنًا في سرعة المنهج رغم تقليل
استعلام SQL واحد لكل طلب. تذبذب الحمل المحلي أكبر من الفرق المقاس.
ما زال زمن 3000 طلب مرتفعًا، ولم يُختبر عبر شبكة عامة أو استضافة إنتاج.
استُخدم محاكي تخزين بذاكرة مؤقتة بلا إنشاء أو حذف ملفات بيانات.
