# Frontend Foundation

Install from repository root with `npm install`, then `npm run dev`.

Angular Standalone + route lazy-loading + SCSS + Tailwind v4 config + CDK dependency + ESLint/Prettier/Playwright configs are in place. The dashboard is a visible shell only; role/auth routes, lesson logic and APIs are still tracked as pending in `docs/BUILD_PROGRESS.md`.

Note: Playwright browser binaries must be installed separately only when you need E2E tests (`npx playwright install` from this directory).
