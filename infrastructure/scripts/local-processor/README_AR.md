# أداة تجهيز درس Shadowing على Windows

نزّل الحزمة من صفحة «معالجة المحتوى» بحساب Admin، وفك ZIP ثم شغّل `Install.cmd` مرة واحدة. هذه الحزمة لـWindows x64. قد يطلب Windows موافقة تشغيل الملف، وموافقة تثبيت Microsoft Visual C++ Runtime إذا كان غير موجود. التثبيت يستخدم Python 3.12 وFFmpeg من winget ثم WhisperX 3.8.6 وTorch CPU 2.8 داخل venv معزولة؛ يحتاج إنترنت ومساحة عدة GB. النموذج الإنجليزي وبيانات اللغة ينزلان أثناء التثبيت على الكمبيوتر. لا تستخدم Python 3.14.

الحفظ داخل `%LOCALAPPDATA%\ShadowingEnglishV2\LocalProcessor`. شغّل الأداة لاحقًا من Start Menu → Shadowing V2 Local Processor. لا يلزم إبقاء نافذة الموقع مفتوحة أثناء المعالجة، لكن نافذة الأداة يجب أن تظل مفتوحة. لا يوجد تشغيل كخدمة ولا فتح منفذ للشبكة. الأداة تستمع فقط إلى `127.0.0.1:43127`.

الأداة لها ربط حساب واحد وأصل موقع واحد وقت التشغيل. تغيير الحساب أوعنوان الموقع يحتاج إغلاق نافذتها ثم تثبيت حزمة الربط الخاصة بالحساب/الموقع الجديد؛ النماذج تُستخدم مجددًا، وملفات الدروس تُعزل في مجلد مستقل لكل حساب وأصل. لكل مسؤول تجهيز جهازه وربطه. حساب Teacher الحالي لا يحصل على صلاحية إنشاء المحتوى؛ الإنشاء متاح لحساب Admin حسب قواعد V2.

اتصال الموقع يُربط تلقائيًا من حزمة التنزيل. اسمح للمتصفح بالوصول للجهاز المحلي عندما يطلب ذلك. الربط مقيّد بأصل الموقع وحساب الأدمن في ملف `shadowing-link.json`؛ الملف يحتوي مفتاح اتصال محلي فاحتفظ به خصوصيًا. لا توجد فيه كلمة مرور الموقع أوcookie أومفتاح AI سحابي. لو مسحت بيانات الموقع، استخدم «استيراد ربط أداة مثبتة» واختر هذا الملف من مجلد الأداة. لو الأداة مثبتة لكن مغلقة، شغّلها ثم اضغط «تحقق من الاتصال»؛ لا تعِد تنزيل النماذج.

ارفع صوتًا/فيديو حتى 100 MB و10 دقائق، واكتب مقطع تدريب إنجليزي واحدًا في كل سطر (حتى 20). النص لازم يطابق الكلام الفعلي؛ هذه forced alignment وليست استخراج محتوى تعليمي. الإعدادات تلقائية: English alignment، تشغيل CPU، WAV PCM16 mono 16kHz، 150ms قبل المقطع و100ms بعده. يمكن تعديل الهامش بين 0 و1000ms من الصفحة. لا نثبت CUDA تلقائيًا؛ CPU أبطأ لكنه أبسط على Windows.

راجع كل نص وحدود كل مقطع واسمع الصوت قبل النقل إلى منشئ الدرس. يمكن تعديل الحدود وإعادة التقطيع دون إعادة تحميل النموذج. لا نحفظ ولا ننشر دروسًا في الموقع تلقائيًا. مخرجات الأداة تتوافق مع حد V2 الحالي: WAV واحد لكل جملة حتى 2 MB. الصوت والنص يذهبان إلى خدمة loopback المحلية فقط أثناء المعالجة. الحفظ إلى Backend يحدث بعد ضغط «احفظ الدرس» في منشئ الدرس، والنشر فعل مستقل.

«تنزيل نسخة من النتيجة» يصنع ZIP تحتوي manifest.json وملفات WAV. يمكن استيرادها في منشئ الدرس بدون اتصال الأداة. الملف لا يعتبر نسخة DB أومنشورًا للطلاب. حذف النسخة المحلية فعل صريح من الصفحة، ولا يحذف الدرس المحفوظ في الموقع. الأداة تحتفظ حتى 30 عملية، وتظهر رسالة عندما يلزم حذف نتائج قديمة.

إذا منع المتصفح اتصال الموقع بالكمبيوتر، شغّل الأداة ثم Start Menu → Shadowing V2 Prepare Lesson ZIP. اختر الصوت وملف TXT إنجليزي UTF-8 (كل سطر مقطع تدريب)، ثم عنوان الدرس ومكان حفظ ZIP. المعالجة تستعمل الخدمة المحلية نفسها والإعدادات نفسها. استورد النتيجة من الصفحة أو منشئ الدرس، واستمع للمقاطع وأكد المراجعة قبل الحفظ.

إغلاق الأداة أثناء المعالجة يجعل العملية السابقة «متوقفة» عند التشغيل التالي؛ بدءها مجددًا فعل صريح. أداة CPU تعمل بمهمة واحدة وحتى أربعة threads، وتخرج ذاكرة النموذج عند انتهاء المهمة أوإلغائها. ابدأ بدرس قصير لتجربة جهازك؛ حد 10 دقائق هو حد إدخال، وليس وعدًا بزمن أواستهلاك ذاكرة ثابت على جميع الأجهزة. احفظ نسخة ZIP قبل حذف أي نتائج قديمة. ملفات كل حساب موجودة تحت `jobs` في مجلد بمعرف مشتق من الحساب والموقع.

النسخة الحالية تجهز Shadowing فقط. Qwen/Ollama، Vocabulary/Quiz، وشات الطالب المباشر ليست ضمن هذه الحزمة. لا يوجد نموذج لغة إضافي أوdownload خفي. حفظ WAV النهائية في Production منفذ عبر Azure Blob Storage الخاصة بعد ضبط Backend حسب دليل `docs/RUNBOOKS/AZURE_SHADOWING_MEDIA_AR.md` في مصدر V2. Development يستعمل التخزين المحلي افتراضيًا. لا يحتاج الكمبيوتر مفتاح Azure، ولا يُرفع المحرك أوالنموذج. ضبط الاستضافة وفحص Windows الفعلي يظلان مطلوبين؛ نجاح الاختبار المعزول ليس شهادة Production.

التراخيص: كود V2 يتبع قرار ترخيص المشروع؛ WhisperX BSD-2-Clause، وFFmpeg تعتمد رخصته على البنية المثبتة. محاذاة الإنجليزية تستخدم WAV2VEC2_ASR_BASE_960H من torchaudio؛ لا نشغل diarization ولا نموذج MMS غير التجاري. راجع تراخيص الأوزان والتوزيع قبل توزيع binary تجارية. تفاصيل ترخيص المشروع نفسه لم تُحسم بعد.


## التشغيل التلقائي
بعد نجاح `Install.cmd` يتم تسجيل الأداة للمستخدم الحالي لتعمل في الخلفية تلقائيًا عند تسجيل الدخول إلى Windows. لا تحتاج لفتح `Start.cmd` في الاستخدام العادي. `Start.cmd` يبقى فقط للتشخيص اليدوي.
